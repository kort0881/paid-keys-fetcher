# Paid Keys Fetcher

Автоматический сборщик конфигураций для VPN-клиентов (v2rayN и совместимые).
Раз в сутки по расписанию GitHub Actions скачивает актуальный список
конфигураций по секретной ссылке и публикует его как артефакт.

## Как это работает

1. GitHub Actions запускает workflow по расписанию (03:00 UTC) или вручную.
2. Скрипт `fetch_paid_keys.py` скачивает данные по URL из секрета `PAID_URL`.
3. Ответ сохраняется в `results/paid.txt`.
4. Файл публикуется как артефакт `paid-keys` (хранится 1 день).

## Настройка

1. Откройте **Settings → Secrets and variables → Actions**.
2. Создайте секрет:
   - **Name:** `PAID_URL`
   - **Value:** ваша ссылка на источник конфигураций
3. (Опционально) Создайте переменную `UA`, если нужно изменить User-Agent.
   По умолчанию используется `v2rayN/6.23`.

## Ручной запуск

- **Actions → Fetch Paid Keys → Run workflow**.

## Локальный запуск

```bash
pip install -r requirements.txt
export PAID_URL="https://example.com/sub"
python fetch_paid_keys.py
```

Файл появится в `results/paid.txt`.

## Получение результата

После успешного запуска откройте страницу нужного workflow-рана
и скачайте артефакт `paid-keys` внизу страницы.

## Замечания

- Артефакт хранится **1 день**. Если нужна более длительная история —
  добавьте шаг коммита или отправку в внешнее хранилище.
- Scheduled workflow автоматически отключается GitHub, если репозиторий
  неактивен 60 дней. Достаточно периодически делать любой коммит
  или запускать workflow вручную.
